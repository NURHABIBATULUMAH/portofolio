# 📸 PANDUAN MENGISI & MENGGANTI FOTO PORTOFOLIO

Halo! Anda bisa dengan sangat mudah mengganti semua foto di website ini tanpa perlu mengubah kodingan HTML/CSS. Cukup masukkan file foto Anda ke dalam folder ini (`assets/images/`) dengan nama file yang sesuai di bawah ini:

---

### 1. 👤 FOTO PROFIL ANDA (HERO SECTION)
- **Nama File**: `profile.jpg` *(atau `profile.png`)*
- **Rekomendasi**: 
  - Rasio 1:1 (persegi) atau 3:4 (setengah badan).
  - Pakaian rapi (jas almamater UTM / kemeja / blazer).
  - Background bersih atau semi-kantor.

---

### 2. 💻 FOTO SCREENSHOT PROYEK-PROYEK ANDA
Cukup ambil tangkapan layar (screenshot) aplikasi Anda yang sedang berjalan, lalu simpan ke folder ini dengan nama berikut:

| Nama File | Untuk Proyek | Rekomendasi Tampilan |
| :--- | :--- | :--- |
| `apotek.jpg` | **Sistem Manajemen Apotek** | Halaman Dashboard POS kasir atau tabel stok obat |
| `retrieval.jpg` | **Information & Dense Retrieval** | Halaman form pencarian dokumen atau hasil retrieval semantik |
| `hotel.jpg` | **Sistem Pemesanan Hotel (Project PAW)** | Halaman katalog kamar atau form tanggal reservasi |
| `toefl.jpg` | **Platform Simulasi TOEFL** | Halaman ujian TOEFL saat timer berjalan atau player audio |
| `datascience.jpg` | **Proyek Sains Data (PSD)** | Screenshot grafik EDA (Heatmap korelasi / Confusion Matrix / Jupyter) |
| `pendata.jpg` | **Penambangan Data (Pendata)** | Screenshot visualisasi clustering K-Means / scatter plot / data mining |

> 💡 **Tips Format & Rasio Screenshot:**
> - Format yang disarankan: `.jpg` atau `.png`.
> - Rasio terbaik: **16:9** (landscape layar laptop/PC).
> - Resolusi ideal: 1280x720 atau 1920x1080 piksel agar jernih dan tajam.

---

### 3. 📜 FOTO SERTIFIKAT (OPSIONAL)
Jika Anda memiliki scan/foto sertifikat fisik atau file PDF sertifikat yang sudah di-export ke gambar:
- `sertifikat-bnsp.jpg` : Scan Sertifikat Kompetensi BNSP
- `sertifikat-dicoding.jpg` : Sertifikat kelulusan Dicoding

---

### ⚡ APA YANG TERJADI JIKA FOTO BELUM DIISI?
Website telah dilengkapi dengan **fitur fallback otomatis cerdas**. Jika file foto belum ada atau nama file tidak sengaja salah, website **tidak akan menampilkan gambar rusak/pecah**, melainkan menampilkan banner ilustrasi grafis teknologi modern yang rapi.
